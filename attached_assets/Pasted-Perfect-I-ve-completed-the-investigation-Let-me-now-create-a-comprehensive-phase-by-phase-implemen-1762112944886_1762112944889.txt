Investigation Summary
The architect has confirmed the investigation report's findings and identified the root causes:
Critical Findings:
Navigation Component Divergence: Header (protected) uses useAuth() hook internally, while Navigation (public) expects user props - causing inconsistent rendering
ProtectedRoute Flicker: Renders null during loading, triggers redirects on partial user objects
React Query Over-refetching: refetchOnMount + refetchOnWindowFocus causes redundant API calls during navigation while token refresh is in-flight
Aggressive 401 Handling: API client logs out immediately on 401 before refresh attempts complete
Token Refresh Timing: Fires late (80% lifetime) and isn't properly cancelled/restarted on login/logout
Token State Divergence: currentToken in token-refresh.ts vs authToken in api-client.ts can desync
Security Status: ✅ No security issues found
